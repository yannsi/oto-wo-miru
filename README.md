# 音を見る・音で文字を送る

音でデータを送る仕組みを、一から作って学ぶ練習です。

| 段階 | ページ | できること |
|---|---|---|
| 第1段階 | [音を見る](https://yannsi.github.io/oto-wo-miru/) | マイクの音をスペクトログラム（縦＝高さ、横＝時間、明るさ＝強さ）で表示 |
| 第2段階 | [音で文字を送る](https://yannsi.github.io/oto-wo-miru/okuru.html) | 文字を「低い音＝0／高い音＝1」の音にして送り、別の端末で文字に戻す |

## 第2段階のしくみ

- 方式：FSK。使う高さは2組から選べる

  | 組 | 0の音 | 1の音 | 合図（ゆっくり／ふつう／はやい） |
  |---|---|---|---|
  | 聞こえる音 | 1800Hz | 2400Hz | 1000／1200／1400Hz |
  | 聞こえない音 | 18500Hz | 19100Hz | 17500／17800／18100Hz |

- 最初に0.4秒の「合図の音」。合図の高さで、組と速さを伝える（1ビット：ゆっくり0.05秒・ふつう0.03秒・はやい0.02秒）
- 受け取る側は2組を同時に聞く。聞こえない音の組は、15kHzより低い音（話し声・物音）をフィルタで取り除いてから読むので、話し声の多い場所でも混ざりにくい
- 形：`[合図] [同期 10100101] [長さ] [文字のバイト…] [検査 CRC-8]`
- 受け取る側は、決まった高さだけを測るゲルツェル法で0と1を読み、同期の目印でタイミングを合わせる
- 最大60バイト（日本語は1文字3バイト）

マイクは https のページ（GitHub Pages）か、PCで開いたローカルファイルで使えます。
音声を外部に送ることはなく、すべてブラウザの中で計算しています。
