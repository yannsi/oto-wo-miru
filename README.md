# 音を見る・音で文字を送る

音でデータを送る仕組みを、一から作って学ぶ練習です。

| 段階 | ページ | できること |
|---|---|---|
| 第1段階 | [音を見る](https://yannsi.github.io/oto-wo-miru/) | マイクの音をスペクトログラム（縦＝高さ、横＝時間、明るさ＝強さ）で表示 |
| 第2段階 | [音で文字を送る](https://yannsi.github.io/oto-wo-miru/okuru.html) | 文字を「低い音＝0／高い音＝1」の音にして送り、別の端末で文字に戻す |
| 第3段階 | [音で絵を送る](https://yannsi.github.io/oto-wo-miru/e.html) | 絵の明るさを音の高さにして送り、受け取る側で1行ずつ描く（FAX・SSTVと同じ考え方） |
| 第4段階 | [音でファイルを送る](https://yannsi.github.io/oto-wo-miru/file.html) | ファイルをパケットに分け、リード・ソロモン符号で直しながら、1バイトも違わずに届ける（数KBまでの短い文字のファイル向け） |

## 第2段階のしくみ

- 方式：FSK。使う高さは2組から選べる

  | 組 | 0の音 | 1の音 | 合図（ゆっくり／ふつう／はやい） |
  |---|---|---|---|
  | 聞こえる音 | 1800Hz | 2400Hz | 1000／1200／1400Hz |
  | 聞こえない音 | 18500Hz | 19100Hz | 17500／17800／18100Hz |

- 最初に0.4秒の「合図の音」。合図の高さで、組と速さを伝える（1ビット：ゆっくり0.05秒・ふつう0.03秒・はやい0.02秒）
- 受け取る側は2組を同時に聞く。聞こえない音の組は、15kHzより低い音（話し声・物音）をフィルタで取り除いてから読むので、話し声の多い場所でも混ざりにくい
- 形：`[合図] [同期 10100101] [長さ] [文字のバイト…] [検査 CRC-8]`
- 受け取る側は、決まった高さだけを測るゲルツェル法で0と1を読み、同期の目印でタイミングを合わせる
- 最大60バイト（日本語は1文字3バイト）

## 第3段階のしくみ

- 方式：明るさをそのまま音の高さにする（アナログFM。FAX・SSTVと同じ）。雑音が入っても絵は壊れず、ざらつくだけ
- 聞こえる音：黒1500Hz〜白2300Hz、行の合図1200Hz／聞こえない音：黒18100Hz〜白18900Hz、行の合図17800Hz
- 最初に0.4秒の合図。高さで大きさを伝える（はやい64×64・約9秒／ふつう96×96・約22秒／きれい128×128・約43秒）
- 受け取る側は、真ん中の高さの音を掛け合わせて「ずれが回る速さ」から高さを測る。行ごとに行の合図を探して、時計のずれを直す

## 第4段階のしくみ

- 方式：MFSK16。16の高さ（100Hzおき）を使い、1回の音で4ビット。1バイト＝音2つ

  | 組 | データの16の高さ | 合図（ゆっくり／ふつう／はやい） |
  |---|---|---|
  | 聞こえる音 | 1300〜2800Hz | 700／900／1100Hz |
  | 聞こえない音 | 17700〜19200Hz | 16900／17100／17300Hz |

- 1つの音の長さ：ゆっくり0.04秒・ふつう0.025秒・はやい0.015秒。聞く長さを0.01秒の倍数にして、16の高さがおたがいに混ざらないようにしている
- パケット：`[合図 0.16秒] [同期 6音] [ファイル番号][パケット番号][全部の数] [中身 64バイト] [CRC-16] [リード・ソロモン符号 16バイト]`
- 0番のパケット（表紙）：ファイル名・元の大きさ・ちぢめたか・ファイル全体の指紋（CRC-32）
- リード・ソロモン符号 RS(85,69)：GF(256) の上で計算。1つのパケットの中の8バイトまで、どこが壊れても直せる。直したあとCRC-16で確かめる
- 合図はパケットごとに付け、毎回タイミングを合わせ直すので、長いファイルでも時計のずれがたまらない
- 合図の見つけ方：決まった19の高さの中で合図の高さがどれだけ目立つかで判断する（雑音はどの高さにも入るので、雑音に強い）
- 直せなかったパケットは、くり返し送ったときの次の周で埋める（2回／止めるまで）
- 文字のファイルは deflate でちぢめてから送る（パケットの数が減るときだけ）。送れるのは、ちぢめたあとで約16KBまで
- 速さは1秒に約15バイト（ふつう）。音という通り道が細いため、PDFや写真のような大きなファイルには向かない。実用になるのは数KBまでの短い文字

## オフラインで使う

一度ページを開くと、ページ一式が端末にしまわれ、圏外や機内モードでも開けます（`sw.js`）。
iPhoneは Safari の共有ボタン →「ホーム画面に追加」で、アプリのように置けます。
文字のやり取りは音だけで行うので、ネット・Wi-Fi・Bluetoothは使いません。
ページを直したときは `sw.js` の `VERSION` を1つ上げます。

マイクは https のページ（GitHub Pages）か、PCで開いたローカルファイルで使えます。
音声を外部に送ることはなく、すべてブラウザの中で計算しています。
